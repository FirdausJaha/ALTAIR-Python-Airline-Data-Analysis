# ALTAIR – Airline Data Analysis System

ALTAIR – Airline Data Analysis System is a student project developed to analyze an airline dataset and present the results through an interactive web dashboard.

The project follows a structured data-analysis workflow starting from dataset loading and exploration, followed by data preprocessing, feature engineering, exploratory data analysis, statistical analysis, visualization, and interpretation of results.

The final analytical results are presented through the ALTAIR interactive dashboard, which also provides an interactive Data Explorer for searching, filtering, modifying, and downloading records.

## Project Overview

The project analyzes passenger, flight, geographic, airport, and time-related information available in the airline dataset.

The analysis covers:

- Passenger age and gender
- Age groups
- Nationality distribution
- Country distribution
- Departure airports
- Arrival airports
- Continental distribution
- Flight-status distribution
- Departure dates
- Monthly patterns
- Day-of-week patterns
- Derived analytical features
- Statistical summaries
- Relationships between selected attributes

The project combines a Python-based data-analysis workflow with an interactive browser-based dashboard.

---

## Objectives

The main objectives of the project are:

1. Load and inspect the airline dataset.
2. Understand the structure, attributes, data types, and data quality.
3. Check missing values and duplicate records.
4. Clean and prepare the dataset for analysis.
5. Create additional analytical features from existing fields.
6. Perform exploratory data analysis (EDA).
7. Apply descriptive and basic statistical analysis.
8. Generate different types of data visualizations.
9. Produce processed datasets and analytical outputs.
10. Present analytical findings through an interactive dashboard.
11. Provide an interactive Data Explorer for record-level exploration.
12. Demonstrate practical data-analysis concepts covered in the Data Analysis Essentials course.

## Dataset

The project uses the **Airline Dataset** available through Kaggle:

https://www.kaggle.com/datasets/iamsouravbanerjee/airline-dataset

The dataset contains passenger, airport, geographic, date, and flight-status information.

The original dataset contains the following 15 attributes:

| Attribute | Description |
|---|---|
| Passenger ID | Unique passenger identifier |
| First Name | Passenger first name |
| Last Name | Passenger last name |
| Gender | Passenger gender |
| Age | Passenger age |
| Nationality | Passenger nationality |
| Airport Name | Departure airport |
| Airport Country Code | Country code associated with the airport |
| Country Name | Country associated with the airport |
| Airport Continent | Continent associated with the airport |
| Continents | Continent information |
| Departure Date | Flight departure date |
| Arrival Airport | Arrival airport |
| Pilot Name | Pilot information |
| Flight Status | Flight status |

The working dataset contains approximately **98,619 records**.
